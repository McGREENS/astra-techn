ASTRA LOGO - PRODUCTION FILES

SVG/   Vector masters. Scale to any size. Use these for print, signage and web.
PNG/   Transparent background, 4000 px wide (logo) / 3000 px wide (mark).
PDF/   Vector PDF of the full logo, for printers (the silver one sits on black).
Presentation/   The logo placed on black and on white, 4000 px wide.

Versions
  silver   Metallic version with shading and the light flare. For dark backgrounds only.
  black    One solid colour (#0B0B0D). For light backgrounds, stamps, engraving, single-colour print.
  white    One solid colour (#FFFFFF). For dark or photographic backgrounds.

Lockups
  astra-logo-*              Mark + ASTRA + tagline
  astra-logo-*-no-tagline   Mark + ASTRA
  astra-mark-*              Mark only (icon, avatar, favicon source)

Notes
  - All lettering is converted to outlines; no fonts need to be installed.
  - The tagline is set in Montserrat Medium (SIL Open Font Licence, licence included).
  - The black and white versions are plain filled paths with no strokes, effects or
    transparency, so they are safe for vinyl cutting, embroidery set-up and spot colour.
  - The silver version uses gradients and soft transparency. Use the PNG where a
    program does not display the SVG gradients correctly.
  - In the one-colour versions the back of the orbit ring is slightly heavier than in
    the silver version so it holds at small sizes.
